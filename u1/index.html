台科資工大一上心得

前言

好不切實際，不知道為什麼最近幾年都過的好快，也沒想到我會在期中前發顛寫這個，總之不知道為什麼我現在在臺科大讀大一，我還是覺得這一切都好像一場夢，我到了那個我最想去的台北，到了每個人最想去的台大的隔壁。

校內

先來看看我這學期的選課以及一些安排，總之正如大部分的學校我們也有必修的國英文，先講英文的部分好了我們在英文有分不同的模組(難度)然後不同難度有免修不同的學分數，然後我選的是最簡單的模組(也是免修最少的)，國文則是選看起來最水的(但有報告)。
再來是系必修的部分，有離散、微積分、計算機程設、資工導論。在期中看起來其實都還不錯，因為一些原因其實我蠻想在某些課程跳去隔壁班(不同老師同課)(然後最後失敗了)。資工導論的部分老師人很好但有些東西我覺得它真的比較像介紹資工而不是像一堂課，讓人噁心的地方則是課程難度普通(對我來說可翹且可考試拿高分)，但老師會考斜咖題目，所以強制你上課。微積分似乎是因為是新老師所以有些部分感覺不是那麼會教，但由於微積分是最有可能被先修的，所以這部份被放大的不是那麼大。再來是離散，也是課程難度普通，老師上課速度慢(開學一個月只教一個單元，同時隔壁班教學進度是我們的2倍左右)，然後期中要考三個單元，最後期中看起來要延後2w。程設就是很水的用 C 教競程與一些 C 的記憶體相關。
最後是一些如果考慮台科需要注意的事情，體育有必修六個學期，課程選擇時會有限定能選的人，要選你不能選的課要透過加簽，還有要你服務社會的社會實踐學分。

心得的部分是轉學考真的難度好高，先暫時不考慮，再來是交換，交換的難度感覺正常發揮選擇機會蠻多的，未來大概率會考慮，然後沒選擇修外文的原因是它只能算自由學分而且能選的很少，最後最靠背的是居然有課程可以選然後加退選的時候到教室才說不開了要我自己退。

校外

校外的部分還是往競程發展，科大可以進 ICPC 的方法有 TUPC、TOPC、NCPC、CPE，但 TUPC 在入學前就打了所以打不了，開學後一兩個禮拜就打 TOPC 了，然後我還沒找到隊友所以也沒打到，最後也因此只有打 NCPC。NCPC 因為初賽台科只有一隊所以我們只要解一題就有決賽打。決賽我發揮的很糟，題目爛是一點但我自己也卡 pB 沒找到要單調的性質，吃了很多罰時，感覺打的好一點進前40不是問題。
資安的部分是有加資安社，跟著學了一點資安，然後現在覺得自己想學的好多，有點迷惘不知道該從哪邊開始，有英文、西文、法文、德文、各種程式語言、資安能力、專案能力。現在卡的有點死。

結語

現在想邊開發邊學，想統整我會用到的東西然後彙整成一個 app 來降低系統負擔，外文的部分可能英文用死神單字繼續拼，非英文的真的就每天 dulingo 跟自己很閒才會碰了，希望我 gpa 能有 4+。
